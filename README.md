## Estudio de color

Reduce una imagen a pocos colores para ver con claridad qué tonos tiene. La hice con ChatGPT para ayudarme con mis pinturas que hago con pasteles suaves.

- Reduce la imagen a entre 2 y 64 colores y muestra la paleta.
- Al hacer clic en un color, muestra solo las zonas donde aparece.
- Agrega una cuadrícula y te da el código de color de cualquier píxel.

Todo ocurre en el navegador: la imagen no se sube a ningún servidor.
